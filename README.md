# Weather App

A simple weather web app built with HTML, CSS (Tailwind) and vanilla JavaScript. Search for any city and see its current temperature, humidity and wind speed, along with a matching weather icon.

## Features

- Search weather by city name
- Shows temperature, humidity and wind speed
- Weather icon that changes with the conditions (Font Awesome)
- Input and data reset when you focus the search box, so old results never linger while you type a new city
- Placeholder values (`--`) shown when there is no data

## Tech Stack

- HTML5
- Tailwind CSS
- JavaScript (ES6+)
- Font Awesome (icons)
- OpenWeatherMap API (weather data)

## How to Use

1. Click or tab into the search box (the old data is cleared automatically)
2. Type a city name
3. Press Enter or click the search button
4. View the temperature, humidity, wind speed and weather icon
